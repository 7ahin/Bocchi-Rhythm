# Bocchi Rhythm

## Project Goal
Create a playable 2D rhythm-game MVP within one week.

## Target Platform
Windows PC

## Engine
Godot 4

## Game Type
4-lane rhythm game.

## MVP Features
- Four rhythm lanes
- D/F/J/K controls
- Music playback
- Note chart system
- Timing judgement
- Combo
- Score
- Results screen
- One playable song

## Out of Scope
- Multiplayer
- Story mode
- Online leaderboard
- Shop system
- Character progression
- Mobile version
- Large song library

## Success Criteria
The player can launch the game, select a song, complete a rhythm chart,
receive a score and judgement breakdown, then retry or return to menu.
